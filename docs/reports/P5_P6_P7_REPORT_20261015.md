## 做成了什么
**P4 收尾**
- 发现（第二次真实写烟测）：agy 无头模式下 `request-review` 连工作副本内的写入也软拒绝。修复：`RunRequest.allowed_paths`（Kernel 从合同填入）→ 适配器只为写任务写 `permissions.allow = [write_file(<路径>)…]`（相对 + 绝对两种写法），每条规则写入前核对（不许命令/通配符/正则/根/越界）；备选 `--mode accept-edits` 已实现（`PAR_AGY_WRITE_STRATEGY`）但没用到。
- **真实验证（你批准的一批最多 3 次中，用了 2 次真实模型调用）**：规则被 CLI 读到并保留，编辑步骤 `DONE`，agy 完成任务，Kernel：`REVIEW_REQUIRED`、补丁 1 文件 +1 −1、边界 0 违规、Kernel 自己跑的检查 PASS；真实项目、`~/.gemini`、真实数据目录均无变化；额度：Gemini 周额度 99%、五小时 99%。
- 附带发现并修复：一次**掉线**（`request failed … EOF`）原被判成执行失败，现为暂时性错误（补丁保留，重试时由接力带走）。两条真实事件流已存为测试样本。

**P5**：`par mcp serve` / `par mcp config`——7 个受限工具（`submit_task` `get_task_status` `get_task_result` `cancel_task` `review_task` `run_task` `list_tasks`），名单有测试钉死、源码里扫不到任何批准/验收类标识符；提交者固定 `coordinator`；答案短、脱敏、标明“Worker 的话未验证”；桥替一个有名字的主控说话，被替换后不能再提交或启动。`par takeover export/confirm/status`：只读接管包（任务树与事实、Harness 路径与哈希，没有对话和 Worker 的话）+ 显式确认，同一时刻一个主控。

**P6**：接力（`par task retry` 默认接着上一次已验证的改动继续；`--fresh` 从基线重来；补丁不可用时给出路）；人工交接 `par task handoff / import`（交接包：提示词、私有副本、中文步骤；带回来的文件夹/补丁/文字按普通 Worker 的标准验证；应用自己生成的设置目录忽略）；官方资料里 WorkBuddy 与 TRAE 桌面版都没有可用的程序接口，所以不自动化。

**P7**：`par serve`（四页：工作台、模型配置、任务管理、系统健康；127.0.0.1 + 令牌 + Host/Origin 校验 + 严格 CSP；默认只读，`--allow-write` 才能写；每个写动作带 `expected_version`、有审计行；禁用的按钮显示原因；能准备交接/带回结果、切换 Profile、启停 Provider（严格、有备份））。真实浏览器演示：准备交接（TRAE）→ 在导出的文件夹里修改（应用顺手建了 `.trae/`）→ 带回结果 → Kernel 验证（1 文件，检查 PASS，`.trae` 当噪声忽略）→ `REVIEW_REQUIRED`。

**一个旧安全缺陷（顺手发现并修复）**：脱敏函数在 20 万字符的字母串、几千个私钥开头标记这类输入上是二次方时间，一行异常的 Worker 输出就能卡住 Kernel 线程。现在全部有界或单遍扫描，有最坏输入测试和变异检验；对旧实现做了差分测试（6000 条真实形状的字符串，零差异）。

4. **你的机器到 Google 的连接偶尔被掐断**（`EOF`）：一次预检失败（没耗额度）、一次运行结束时掉线；重试即可，接力会带走已改对的补丁。
5. 控制台里「带回结果」只能带回这次交接导出的那个文件夹（有意不接受调用者给的路径）；用补丁或文字带回仍用命令行。
6. 控制台的页面是原生 HTML+JS，没有浏览器自动化测试（用静态规则测试 + 一次真实浏览器走查）。
